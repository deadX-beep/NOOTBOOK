# Notebook

A simple personal notebook app with reminders, built as a single HTML file. No installation or account needed just open it in a browser.

## Features

- Create, edit, and delete notes
- Color-tag notes to organize them
- Pin important notes to the top
- Set reminders on any note, with an upcoming-reminders panel
- Search across all your notes
- Notes autosave as you type

## Download

[Download notebook.html](https://github.com/deadX-beep/NOOTBOOK/raw/main/notebook%20.html)

Save the file anywhere on your computer and double-click it to open the notebook in your browser.
